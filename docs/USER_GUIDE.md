# Tosun Workflow 사용자 헬프

## 이 프로그램은 무엇인가요?

스토리보드와 모션그래픽 자료를 기준으로 이미지·영상·Remotion 결과를 단계별로 만드는 Codex 워크플로우입니다.

- Codex 플러그인은 자료 해석, 프롬프트 제작, 이미지 생성 작업을 진행합니다.
- runner는 백업, 파일 정리, 상태 기록을 담당합니다.
- 사용자는 네 번만 결과를 확인하고 승인합니다.

## 처음 사용할 때

1. 프로젝트명, 영상 길이, 영상 해상도, 영상 프레임, 화면 비율을 입력합니다.
2. 필요하면 목적, 대상, 플랫폼, 언어, 레퍼런스를 추가합니다.
3. 스토리보드는 파일을 첨부하거나 Codex 채팅으로 작성합니다.
4. 직접 준비한 자료는 작업 폴더에 넣거나 대화에 첨부합니다.
5. 필요한 시퀀스의 명령을 입력합니다.
6. 각 결과를 승인한 뒤 다음 시퀀스로 넘어갑니다.
7. 모션 그래픽 프리뷰 승인 후 풀 렌더를 진행합니다.
8. 풀 렌더 결과를 최종 승인합니다.

필수 정보 입력 양식은 [templates/project-intake-form.md](../templates/project-intake-form.md)입니다.

전체 제작이 아니라 특정 시퀀스만 실행할 수도 있습니다. 중간 결과 인풋을 첨부하면 해당 시퀀스를 확인 후 스킵하고 다음 시퀀스부터 시작할 수 있습니다.

## 입력 파일 구분

- 스토리보드: 내용, 장면 순서, 내레이션, 자막, 시간
- 모션그래픽: 색상, 구성, 전환, 움직임, 시각 레퍼런스

둘이 충돌하면 Codex가 임의로 결정하지 않고 보고하도록 되어 있습니다.

## 이미지 생성 단계

1. 스토리보드 승인 뒤 Codex가 이미지·비디오 프롬프트를 자동으로 만듭니다.
2. `이미지를 생성하라`로 Codex 이미지 생성 기능을 실행하고 결과를 표시합니다.
3. 이미지 승인 뒤 `영상을 제작하라`로 Higgsfield 비디오를 만들고 표시합니다.
4. 비디오 승인 뒤 `모션 그래픽을 제작하라`로 Remotion 프리뷰를 만들고 표시합니다.
5. 프리뷰 승인 뒤 풀 렌더를 만들고 표시합니다.

## 인풋 교체

각 결과가 마음에 들지 않으면 `수정해`라고 말하거나 새 파일·수정 자료를 제공할 수 있습니다.

- `스토리보드 입력 교체해`
- `이미지 입력 교체해`
- `비디오 입력 교체해`
- `리모션 입력 교체해`

이전 파일은 삭제하지 않고 교체 이력으로 보관합니다. 교체한 단계부터 이후 단계만 다시 준비합니다.

## 문제가 생겼을 때

- 현재 상태 확인: `토순 워크플로우 상태 확인`
- 현재 단계 재실행: `이 단계 다시 해`
- 수동 백업: `프로젝트 백업해`
- 로그 확인: 프로젝트의 `events.jsonl`
- 사람이 읽는 결과 확인: 프로젝트의 `reports/`

워크플로우 밖의 현장 운영이나 사람에게 물어봐야 하는 내용은 `궁금한 게 있으면 1층 찬영님한테 가세요 ㅋㅋ`라고 안내합니다.

## 완료 기준

최종 파일이 `public/`에 있고, `manifest.json`에서 해당 단계가 승인 또는 완료 상태여야 합니다. 파일이 없으면 완료로 간주하지 않습니다.
