# Stage 01 — Storyboard

스토리보드 작성 요청이 들어오면 `templates/storyboard-form.md` 양식을 사용합니다.

- 입력 파일이 있으면 내용을 양식에 맞춰 재구성합니다.
- 입력 파일이 없으면 빈 양식을 먼저 보여주고 사용자 작성을 기다립니다.
- 사용자가 작성한 내용은 장면 단위의 구조화된 스토리보드 초안으로 정리합니다.
- 초안을 사용자에게 표시한 뒤 `스토리보드 이대로 진행`이라는 승인 전에는 이미지를 생성하지 않습니다.

- storyboard: 장면, 순서, 메시지, 내레이션, 자막, 길이
- motion_graphic: 색, 레이아웃, 전환, 움직임, 질감, 레퍼런스
- 충돌 시 사용자 승인 전까지 임의로 합치지 말고 충돌을 보고합니다.
- 결과는 JSON으로 먼저 저장합니다.
