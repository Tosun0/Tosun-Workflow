# Core Workflow Instructions

- Preserve the original storyboard wording and distinguish facts from creative direction.
- Treat storyboard inputs as content and timing authority.
- Treat motion-graphic inputs as visual and animation direction.
- Produce structured JSON before producing long prose.
- Keep every stage reproducible from `manifest.json` and its recorded inputs.
- Never claim an external image/video render succeeded without a file existence check.
- Keep public output small, stable, and limited to approved deliverables.
- Accept either Codex-created output or injected user input, but apply the same validation checklist to both.
- Display each result before advancing and stop for explicit user approval.
- Preserve replaced inputs and invalidate only downstream stages.
- The permanent required intake fields are project name, video duration, video resolution, frame rate, and aspect ratio. Do not relax these fields unless the user explicitly requests a change to the default intake rules.
- A storyboard file is optional; create it in Codex chat when no storyboard input is attached.
